# Construction Project Cost & Performance Analysis

## 📊 Data Analytics Project

A Data Analytics project focused on analyzing construction project costs, budgets, delays, contractors, project types, locations, and overall project performance.

The project uses **Python, Pandas, NumPy, Matplotlib, Plotly, SQL, and Power BI** to transform construction project data into meaningful business insights and an interactive dashboard.

## 🎯 Project Objective

The main objective of this project is to analyze construction project data and identify useful insights related to:

- Project costs
- Estimated vs actual budgets
- Budget overruns
- Project delays
- Project types
- Project locations
- Contractor performance
- Construction cost components
- Project area
- Cost per square foot
- Project status

The analysis helps understand **where construction costs increase, which project types experience higher budget overruns, how delays affect projects, and how different contractors and locations perform.**

## 🔍 Analysis Performed

### 1. 💰 Budget & Actual Cost Analysis

Compared the estimated project budget with the actual construction cost.

The analysis helps identify:

- Projects exceeding their estimated budgets
- Difference between estimated and actual cost
- Overall budget performance
- Budget variance across projects

The overall dataset shows a **1.83% budget overrun**, meaning total actual construction spending is approximately 1.83% higher than the total estimated budget.

---

### 2. 📈 Budget Overrun Analysis

Calculated budget overrun for individual projects using the difference between estimated budget and actual cost.

The analysis also calculates the percentage of budget overrun.

The project analyzes budget overruns across:

- Project types
- Locations
- Contractors
- Individual projects

---

### 3. 🏗️ Project Type Analysis

Analyzed construction projects based on project type:

- Residential
- Commercial
- Industrial
- Infrastructure

The analysis compares project types based on:

- Average budget overrun
- Estimated budget
- Actual cost
- Project performance

**Residential projects have the highest average budget overrun among the project types in this dataset.**

---

### 4. 📍 Location-wise Cost Analysis

Analyzed construction costs across different project locations.

The analysis compares:

- Total actual construction cost
- Number of projects
- Average budget overrun
- Average project delay

This helps understand differences in construction activity and project costs across locations.

---

### 5. ⏱️ Project Delay Analysis

Analyzed project completion delays using the `Delay_Days` column.

Projects were analyzed based on:

- Delayed projects
- On-time projects
- Average delay
- Maximum delay
- Project-wise delay

This analysis helps identify projects that require closer monitoring of their planned and actual completion timelines.

---

### 6. 👷 Contractor Performance Analysis

Analyzed contractor performance based on construction projects handled by different contractors.

The analysis includes:

- Total projects handled
- Average budget overrun
- Average project delay
- Overall project performance

This provides a way to compare contractor-related project performance using measurable project metrics.

---

### 7. 🧱 Construction Cost Component Analysis

Analyzed the major components contributing to total construction costs:

- Material Cost
- Labour Cost
- Equipment Cost
- Other Cost

The analysis helps understand how construction expenditure is distributed across different cost components.

---

### 8. 📐 Project Area & Cost Analysis

Analyzed the relationship between project area and construction cost metrics.

The analysis found a strong positive correlation of approximately **0.89 between project area and cost per square foot** in this dataset.

Correlation indicates the strength of the relationship between the variables but does not by itself establish causation.
